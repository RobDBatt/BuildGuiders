## HDR Format Support

- **Dolby Vision:** YES — TCL supports Dolby Vision across 5-Series and above
- **HDR10+:** NO — TCL does NOT support HDR10+ (Samsung-aligned technology; TCL uses Dolby Vision)
- **HDR10:** YES (universal)
- **HLG:** YES (broadcast)
- **IMAX Enhanced:** On QM8 and some 6-Series models

**Key rule:** TCL is Dolby Vision YES, HDR10+ NO.

## Smart TV Platform

- **Roku TV:** Most TCL models sold in North America run Roku TV OS
- **Google TV:** TCL's QM8 and some higher-end models run Google TV
- **Android TV:** Some international models
- ALWAYS check specific model — TCL uses multiple OSes

## Refresh Rate Reality Check

| Series | Native Panel Rate | Marketing Claim |
|--------|-----------------|----------------|
| 6-Series R655 | 120Hz native | "120Hz" accurate |
| 5-Series S555 | Some 60Hz, some 120Hz | Verify per SKU |
| 4-Series S455 | 60Hz native | "120 Motion Rate" NOT 120Hz |

**"Motion Rate 120" ≠ 120Hz native.** The 4-Series uses motion processing to create the appearance of smoother motion on a 60Hz panel. Always distinguish between "120Hz native" and "120Hz motion processing."

## HDMI Configuration (6-Series R655 example)

- **Port 1:** HDMI 2.1, 4K@120Hz, VRR, eARC (check revision — some list eARC on port 2)
- **Ports 2–4:** HDMI 2.0 (4K@60Hz only)
- **Port asymmetry is real.** Not all 4 HDMI ports on TCL 6-Series are HDMI 2.1.

## Panel Type Clarity

- **QM8:** Mini-LED QLED = quantum dot + Mini-LED backlight (bright, punchy, NOT OLED)
- **6-Series:** Mini-LED QLED (not OLED)
- **QLED = LED/LCD with quantum dot enhancement** — not self-emissive like OLED

## CEC & Features

- **CEC name:** Standard HDMI CEC — no proprietary name for TCL
- **Roku remote CEC:** When running Roku TV OS, uses Roku's "1-Touch Play" label
- **THX Certified:** Select 6-Series and QM8 models

## Common Mistakes to Avoid

1. **Never write that TCL supports HDR10+.** TCL uses Dolby Vision, not HDR10+.
2. **Do not confuse Roku TV OS with Google TV.** TCL uses both — check model name.
3. **Never call TCL QLED panels OLED.** QLED is an LCD technology.
4. **Never say all HDMI ports are 2.1 on 6-Series.** Only 1–2 ports are HDMI 2.1.
5. **Do not equate "Motion Rate 120" with "120Hz native refresh."** Different specs.
