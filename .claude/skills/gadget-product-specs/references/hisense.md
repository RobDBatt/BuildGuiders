## HDR Format Support

- **Dolby Vision:** YES — Hisense supports Dolby Vision across U-series and most A-series
- **HDR10+:** NO — Hisense does NOT support HDR10+ (this is a Samsung technology; Hisense skips it)
- **HDR10:** YES (universal)
- **HLG:** YES (broadcast)

**Key rule:** Hisense is Dolby Vision YES, HDR10+ NO. Do not write that Hisense TVs support HDR10+.

## Smart TV Platform

- **VIDAA OS** (on Hisense-branded models for US/EU market)
- Some Hisense models run Google TV (varies by market and product line; check specific model)
- **Roku TV:** Some Hisense TVs sold at Walmart run Roku TV OS

Always verify the OS for a specific model — Hisense uses multiple OSes across its lineup.

## HDMI Configuration (U8N example)

- **Port 1:** HDMI 2.1, 48 Gbps, 4K@144Hz, VRR, eARC
- **Ports 2–3:** HDMI 2.1, 48 Gbps (varies by model revision)
- Check individual model specs — not all ports on all Hisense TVs are HDMI 2.1

## Panel Type Clarity

- **U8N / U9N:** Mini-LED backlit LCD (NOT OLED) — excellent brightness and contrast for price
- **U6N:** QLED = quantum dot filter on LCD backlight (NOT OLED)
- Never write that any Hisense U-series is OLED

## CEC & Features

- **CEC name:** Hisense uses standard "HDMI-CEC" — no proprietary brand name
- **AnyView Cast:** Hisense's screen mirroring protocol (Chromecast-compatible on some models)
- **IMAX Enhanced:** U8N and U9N are certified

## Gaming Features (U8N / U9N)

- **VRR:** AMD FreeSync Premium certified
- **ALLM:** Supported
- **Game Bar:** On-screen gaming stats overlay
- **Input lag:** ~1ms claimed in Game Mode (verify per review)

## Common Mistakes to Avoid

1. **Never write that Hisense supports HDR10+.** Hisense uses Dolby Vision, not HDR10+.
2. **Never confuse VIDAA OS with Google TV.** Most US market Hisense runs VIDAA; some run Google TV.
3. **Never call U-series panels OLED.** They are Mini-LED or QLED (LCD-based).
4. **Do not assume all HDMI ports are 2.1.** Check per model.
5. **Do not claim "120Hz native" for U6N** — 60Hz native panel with motion interpolation to "120Hz."
